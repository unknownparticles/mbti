# MBTI Lab

一个用于自我探索的 MBTI 风格问卷 Skill 和本地预览页面。包含可直接作答的题库，也可以使用兼容 OpenAI Chat Completions 的模型生成自定义问卷。

## 开始使用

直接在浏览器打开 [预览页面](preview/index.html)，选择题库即可答题，无需安装依赖或填写 API Key。

内置题库包括基础版 32 题、完整版 100 题，以及音乐、美食、兴趣、事业、感情和历史人物各 16 题。基础版是完整版的精简版；每套题均覆盖 E/I、S/N、T/F、J/P 四个维度。

完成作答后可查看各维度分数和解析。某个维度平分时显示 `X`，历史人物方案不会强行匹配人物。

## 自定义问卷

填写场景、目标和题数，再配置 API 地址、模型名称与 API Key，点击“生成问卷”。题数最少为 8，模型生成的题目会检查数量、选项和维度覆盖。

- API 地址填写兼容 Chat Completions 的基础地址，例如 `https://api.example.com/v1`，也可以填写完整的 `/chat/completions` 地址。
- Key 仅保存在当前页面内存中，请求由浏览器直接发送到填写的地址。服务商需要允许来自当前页面的跨域请求。
- 如果使用结果页的“生成个性化建议”，同样需要配置模型连接。

## 分享题目

打开题库或生成自定义问卷后，点击“分享题目”。接收者打开链接即可进入同一套题目，无需你的 API Key。链接不会包含 API Key、已选答案或测评结果。

页面必须先部署到接收者可以访问的 HTTP(S) 地址；本地 `file:` 页面不能生成可供他人使用的链接。内置题库使用短链接，自定义问卷将题目放入链接，题目越多链接越长，可能受到聊天软件或浏览器的长度限制。浏览器无法直接复制时，可在弹出的输入框中手动复制。

## Skill

Skill 入口位于 [mbti-skill/SKILL.md](mbti-skill/SKILL.md)。将 `mbti-skill` 目录安装到支持 Agent Skills 的工具后，可用于生成通用或场景定制题目、解释结果和给出建议。

## 结果边界

题库是自编的探索性示例，并非官方 MBTI 测评，也没有经过心理测量验证，不应用于招聘筛选、医疗诊断等高风险决策。历史人物类型是基于公开生平的推测，传记来源不证明其 MBTI；音乐建议是试听方向，不能代表任何类型的必然偏好。

## 项目结构

- `mbti-skill/SKILL.md`：Skill 入口和使用规则。
- `preview/index.html`：浏览器入口。
- `preview/presets.js`、`preview/results.js`：内置题库与结果资料。
- `preview/logic.js`、`preview/app.js`：题目校验、计分和页面交互。
