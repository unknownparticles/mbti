# MBTI 问卷与推荐

使用 MBTI 的四组偏好作为自我探索框架，不宣称题目是官方 MBTI、经过心理测量验证或可以诊断人格。不要用于招聘筛选、医疗诊断等高风险决策，也不要把类型当作能力或行为的确定预测。

## 生成题目

- 默认生成 8 题；用户指定数量时精确遵守，少于 8 题时说明每个维度至少需要 2 题，请用户调整。
- 四个维度 E/I、S/N、T/F、J/P 各至少 2 题；数量不能均分时尽量均匀分配。
- 每题只考察一个维度，提供两个都合理、无明显褒贬的选项，分别对应这个维度的两端。描述具体行为而非让用户直接选择类型。
- 场景或产品定制时，结合受众、使用情境和目标；缺少会改变题目方向的关键条件时先询问。不要为了迎合目标诱导答案。
- 输出题目、选项、每个选项对应的偏好，以及明确计分规则。若面向答题者展示，可把答案映射单独放在题目之后。

## 计分与解读

每个选项为其对应偏好记 1 分；逐维比较两端分数。平分时标记该维度为 X，明确表示结果未定，不猜测类型。给出各维度分数和局限，并建议通过更多题目或反思确认。未回答完时不生成最终类型。

## 推荐

根据用户提供的类型或作答结果，以及具体目标、场景和限制给出可操作的建议，并说明建议与偏好的关联。缺少目标时先询问；包含 X 的类型应提供适合两种偏好的选择。避免刻板印象、绝对化判断及将类型作为唯一依据。

## 预览

仓库内 `preview/index.html` 提供八套内置题目和本地计分，包括 32 题基础版、100 题完整版，以及音乐、美食、兴趣、事业、感情和历史人物各 16 题。内置题目无需 API Key；自定义生成需要兼容 OpenAI Chat Completions 的接口地址、模型和 API Key。Key 仅在页面内存中使用，浏览器会直接将请求发送至用户填写的服务地址。历史人物类型属于未经本人测评的探索性推测；音乐推荐属于试听建议，不能把人格相关性当成个体音乐偏好的证明。
